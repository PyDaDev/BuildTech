# 🖥️ BuildTech

**Construye. Rinde. Disfruta.**

BuildTech es un sitio web de venta de computadores con un **asistente paso a paso** que recomienda y personaliza el PC ideal según el uso que le vas a dar y tu presupuesto. Diseño responsivo, pensado para abrirse desde el celular.

> Proyecto universitario en desarrollo.

## ✨ Características

- Asistente de 5 pasos: **Uso → Presupuesto → Recomendación → Personalización → Servicios**
- Recomendación de configuraciones para estudio, trabajo, gaming, diseño, programación y uso profesional
- Personalización de componentes con cálculo del total en tiempo real
- Diseño responsivo (móvil, tablet y escritorio)

## 🚀 Cómo ejecutarlo en tu equipo

### Requisitos

- [Node.js](https://nodejs.org) (versión LTS)
- [Git](https://git-scm.com)

### Instalación

```bash
# 1. Clonar el repositorio
git clone https://github.com/TU-USUARIO/buildtech.git
cd buildtech

# 2. Instalar dependencias del cliente
cd client
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev
```

Abre en el navegador: `http://localhost:5173`
